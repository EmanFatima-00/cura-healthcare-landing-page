# Cura - AI Healthcare Platform Landing Page

A modern and responsive business landing page for Cura, a fictional AI-powered healthcare management platform for clinics and hospitals.

This page is designed to introduce the product, explain its value for doctors and patients, showcase features and benefits, and convert visitors.

### Deliverables Covered
- Hero section with CTA
- Product introduction
- Features section (6 features)
- Benefits section
- Testimonials section
- Call-to-Action section
- FAQ section
- Professional footer
- Responsive layout
- Hover and scroll interactions

### Tech Stack
- HTML5
- CSS3
- JavaScript
- Google Fonts - Inter & Sora

### How to Run
Just open index.html in browser
